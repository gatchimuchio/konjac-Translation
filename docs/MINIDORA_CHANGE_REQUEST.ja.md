# MINIDORA 独立変更要求 MCR-001

- 起票日：2026-11-09
- 対象：凍結 `MINIDORA-BETA 0.6.0b1` の後継として検討する、独立した公開版
- 状態：**記録済み・未提出**。この文書は外部への連絡や変更承認ではない。
- 根拠：`docs/ENGINE_INTEGRATION.ja.md` に記録した公開コード、配布保証、制御配線例の監査。現行βには実訳操作・言語ペア契約が確認できない。

## 問題

こんにゃく翻訳はMINIDORAを唯一の意味処理・翻訳採否エンジンとする。公開版 `0.6.0b1` の `実行(...)` と `結果を参照(...)` は、呼出側が注入した作用を実行・参照する一般ファサードであり、翻訳能力を証明しない。言語ペア、文脈、逐次出力、停止条件について実訳APIの保証を確認できないため、A02/A06とU01〜U12の実訳経路は `BLOCKED` のままとする。

## 独立版で必要な公開契約

後継版を設計する場合、少なくとも次を公開文書と実行可能な受入証拠で定義する。

1. 型付き翻訳要求。原文参照、明示的な元言語／自動判定状態、訳先言語集合、要求・入力の版、文脈・用語参照、停止期限を受け付ける。
2. 版ごとの能力表。実測・保証された言語ペアと制約を列挙し、未対応ペアは明示的な `UNSUPPORTED` とする。
3. MINIDORAが所有する意味判断・採否と、確定結果の公開形式。確定訳には要求ID、入力版、訳先、結果版、実行版を結び付ける。
4. 逐次出力を提供する場合、暫定／確定の区別、順序番号、切断後の再取得、確定結果を巻き戻さない規則を定義する。提供しない場合は非対応を明示する。
5. 停止・取消・タイムアウトと終端状態の観測可能な意味を定義する。受付応答だけで処理停止を主張しない。
6. エラー・未対応・採否不能時に訳文を成功扱いしないことを公開境界で検証する。
7. 公開API、依存版、変更履歴、ライセンス範囲、固定配布物の改変有無を特定する。

## 必要な検証証拠

- 独立した配布版・commitと、凍結 `0.6.0b1` からの変更差分。
- 宣言された各言語ペアの固定入力／期待条件／実観測値。モデルや外部ASRの値をMINIDORA翻訳品質と混同しない。
- 文脈・用語適用、複数訳先、要求相関、重複、順序逆転、未対応ペアの検査。
- 中断、停止、期限、内部／外部依存エラー時の終端状態と無誤配信の検査。
- 通常系・異常系の回帰証跡と、実装版との再現可能な対応。

## 境界と次の扱い

- 凍結βへの直接修正を要求しない。変更が必要なら別版・別リリースとして扱う。
- R2は後継設計候補であり、本要求の充足証拠ではない。
- Konjacには第二の意味判断エンジン、暗黙の外部翻訳代替、非公開HDS理論を追加しない。
- Ownerの指示なしにこの要求をMINIDORA側へ送付・公開しない。
- 独立版が公開・監査・承認されるまで、Konjacの実訳経路は `BLOCKED`。その間も契約、権限、保存、媒体アダプターなどMINIDORA非依存部分は施工可能な範囲で継続する。
